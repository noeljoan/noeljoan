# Noël Joan 👋

## Intelligence Engineering. Architecture logicielle. Digitalisation industrielle.

Je combine **génie mécanique, ingénierie logicielle et intelligence artificielle** afin de transformer des processus d'ingénierie complexes en systèmes logiciels robustes et évolutifs.

Mon travail repose sur un principe simple, mais exigeant :

> **Les connaissances techniques ne devraient pas rester enfermées dans des tableaux Excel, des fichiers PDF ou des outils isolés. Elles devraient être structurées, compréhensibles, réutilisables et exploitables de manière intelligente.**

Je conçois des solutions à l'intersection de la **méthodologie d'ingénierie, des modèles mathématiques, des données techniques, de l'architecture logicielle, de l'automatisation et de l'IA**.

# 🏗️ Projets d'ingénierie sélectionnés

## 🔩 Smart Materials Database

### Infrastructure de données pour une gestion intelligente des matériaux

Une plateforme centralisée destinée à gérer, valider, analyser et distribuer les données techniques relatives aux matériaux.

Le système combine **bases de données d'ingénierie structurées, traitement de documents assisté par IA, logique de calcul, visualisation, validation basée sur des règles et intégration CAE**.

### Fonctionnalités principales

- Import assisté par IA de fiches techniques
- Gestion structurée des données matériaux
- Validation des données techniques
- Génération de courbes contrainte-déformation
- Génération de courbes S-N
- Validation et contrôle orientés FKM
- Traçabilité des données d'ingénierie
- Workflows d'export vers ANSYS
- Déploiement On-Premise basé sur Docker

L'objectif architectural est de créer une **base de données d'ingénierie fiable** capable de relier les informations matériaux, les calculs, la simulation et les applications d'ingénierie en aval.

---

## 📊 Product Cost Management

### Digitalisation de l'analyse des coûts

Une application basée sur une architecture de données pour l'analyse structurée des **coûts produits et des coûts de fabrication**.

Le projet vise à dépasser les limites des modèles de coûts fragmentés basés sur Excel en proposant un environnement logiciel centralisé pour :

- Structures de coûts produits
- Analyse des coûts de fabrication
- Données techniques structurées
- Workflows multi-utilisateurs
- Calculs automatisés
- Cohérence et traçabilité des données

L'objectif global est de transformer le cost engineering, souvent basé sur une multitude de feuilles de calcul, en un **processus numérique maintenable**.

## 📐 Vérification de résistance selon FKM

### Le calcul d'ingénierie transformé en logiciel

Une plateforme interactive de calcul pour la vérification de la résistance mécanique basée sur la **directive FKM**, avec un accent particulier sur les arbres et les transitions géométriques.

Le projet explore la manière de transformer des méthodes d'ingénierie complexes en une architecture logicielle capable de fournir :

- Des données d'entrée structurées
- Des calculs automatisés
- Une logique de validation
- Des résultats reproductibles
- Des processus de calcul transparents
- Une documentation technique numérique

Le défi fondamental consiste à transformer les connaissances d'ingénierie en une **logique logicielle déterministe, testable et maintenable**.

# 🧠 Philosophie d'architecture

Je m'intéresse particulièrement à l'interface entre **méthodologie d'ingénierie et architecture logicielle**.

Une transformation typique peut être représentée ainsi :

```text
Connaissances d'ingénierie
        │
        ▼
Normes / Directives / Modèles
        │
        ▼
Logique mathématique & physique
        │
        ▼
Validation & règles métier
        │
        ▼
Architecture logicielle
        │
        ▼
API / Bases de données / Interfaces utilisateur
        │
        ▼
Automatisation
        │
        ▼
Workflows assistés par IA
```

L'objectif n'est pas simplement de reproduire un fichier Excel dans un navigateur.

Il s'agit d'**extraire les connaissances d'ingénierie sous-jacentes, de les formaliser, de les valider et de construire une architecture logicielle durable autour de celles-ci**.
