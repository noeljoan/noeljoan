# 🏗️ Ausgewählte Engineering-Projekte

## 🔩 Smart Materials Database

### Engineering-Dateninfrastruktur für intelligente Materialdaten

Eine zentrale Plattform zur Verwaltung, Validierung, Analyse und Bereitstellung technischer Werkstoffdaten.

Das System verbindet **strukturierte Engineering-Datenbanken, KI-gestützte Dokumentenverarbeitung, Berechnungslogik, Visualisierung, regelbasierte Validierung und CAE-Integration**.

### Ausgewählte Funktionen

- KI-gestützter Import technischer Datenblätter
- Strukturierte Werkstoffdatenverwaltung
- Validierung technischer Daten
- Generierung von Spannungs-Dehnungs-Kurven
- Generierung von Wöhler-/S-N-Kurven
- FKM-orientierte Validierung und Prüfung
- Nachvollziehbarkeit technischer Daten
- ANSYS-Export-Workflows
- Docker-basierte Bereitstellung vor Ort

Ziel der Architektur ist eine **zuverlässige Engineering-Datenbasis**, die Materialinformationen, Berechnungen, Simulationen und nachgelagerte Engineering-Anwendungen miteinander verbindet.

## 📊 Product Cost Management

### Digitale Kostenanalyse

Eine datenbankgestützte Anwendung für strukturierte **Produktkosten- und Herstellkostenanalysen**.

Das Projekt adressiert die Grenzen fragmentierter Excel-basierter Kostenmodelle und schafft eine zentrale Softwareumgebung für:

- Produktkostenstrukturen
- Herstellkostenanalysen
- Strukturierte technische Daten

## 📐 FKM-Festigkeitsnachweis

### Ingenieurtechnische Berechnung als Software

Eine interaktive Berechnungsplattform für die mechanische Festigkeitsbewertung auf Basis der **FKM-Richtlinie**, mit Schwerpunkt auf Wellenbauteilen und Kerben bzw. geometrischen Übergängen.

Das Projekt untersucht, wie komplexe ingenieurtechnische Methoden in eine Softwarearchitektur überführt werden können, die:

- strukturierte Eingaben ermöglicht
- Berechnungen automatisiert
- Validierungslogik integriert
- reproduzierbare Ergebnisse liefert
- transparente Berechnungsabläufe ermöglicht
- digitale technische Dokumentation unterstützt

Die zentrale Herausforderung besteht darin, Ingenieurwissen in **deterministische, testbare und wartbare Softwarelogik** zu überführen.

# 🧠 Architekturphilosophie

Mich interessiert besonders die Schnittstelle zwischen **Ingenieurmethodik und Softwarearchitektur**.

Eine typische Transformation sieht so aus:

```text
Ingenieurwissen
        │
        ▼
Normen / Richtlinien / Modelle
        │
        ▼
Mathematische & physikalische Logik
        │
        ▼
Validierung & Fachregeln
        │
        ▼
Softwarearchitektur
        │
        ▼
APIs / Datenbanken / Benutzeroberflächen
        │
        ▼
Automatisierung
        │
        ▼
KI-gestützte Workflows
```

Das Ziel besteht nicht darin, eine bestehende Excel-Tabelle lediglich in einen Browser zu übertragen.

Es geht darum, das zugrunde liegende **Ingenieurwissen zu extrahieren, zu formalisieren, zu validieren und darauf ein nachhaltiges Softwaresystem aufzubauen**.
